# Tools

## Stack (kept to what the brief lists)
- **Frontend**: React + TypeScript (Vite for fast setup)
- **Backend**: Node.js + Express (TypeScript)
- **Database**: PostgreSQL + Prisma ORM
- **Charts**: Chart.js (react-chartjs-2)
- **Docker**: one `docker-compose.yml` for Postgres (and optionally the app)

## Small helper libraries
- `jsonwebtoken` + `bcrypt` – login and roles
- `pdfkit` – generate the PDF certificate
- `zod` – request validation (optional)
- `cors`, `dotenv`

## Free resources
- Videos: Big Buck Bunny, Sintel, Pexels stock videos (direct links)
- Seed data: a few hand-written courses (skip the Kaggle datasets to save time)
- Live class: Jitsi Meet room link (no setup or keys)

## Deliverable tools
- **Architecture diagram**: draw.io or Mermaid
- **Demo**: screen recording with OBS or Win+G / QuickTime
- **API docs**: a simple table in the README (or Postman export)
- **Hosting (optional)**: Render / Railway; otherwise a screen recording is accepted
